# videos/

Put ad video files here, then point to them from `content.js` (for example `"video": "videos/pair1-left.mp4"`).

- Use MP4 (H.264 video, AAC audio) so every browser can play it.
- GitHub rejects files over 100 MB. Aim for about 10–25 MB per ad, at 720p.
- Optional poster stills (`.jpg`) can live here too. Point to them with the ad's `poster` field.
- If either file in a pair is missing, that pair falls back to side-by-side panels automatically.
